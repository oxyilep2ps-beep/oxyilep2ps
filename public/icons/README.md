# PWA icons

Place these PNG files in this folder (`public/icons/`):

| File | Size | Purpose |
|---|---|---|
| `icon-192.png` | 192×192 | Android / Chrome install |
| `icon-512.png` | 512×512 | Android / Chrome splash + install |
| `icon-192-maskable.png` | 192×192 | Adaptive icon (keep the orange ring inside an ~80% safe zone) |
| `icon-512-maskable.png` | 512×512 | Adaptive icon, same safe zone |
| `apple-touch-icon.png` | 180×180 | iOS home screen |

Background: `#000000`. Accent ring: `#F97316`.
`icon.svg` is a vector reference of the mark — export PNGs from it if needed.
